A calm board that shows who needs you, and why every number moved.

This round covers foundations (1b) and the main board in light (1c), dark (1d) and a sample client theme at 1280 (1e). The boards are live: select a member, open a reason chip, change a style, plan an action, sort the team, or press Cmd K.

Assumptions to confirm

Source docs. The Interface Spec, Simulation Design, GenieKreator Config Spec and Teardown were not attached, only the screenshot. Member names and Skill, Morale, Result values come from the screenshot. Trust values, funnel roles, day costs, events and quotes are my placeholders until I see the Teardown.

Typeface. The Genie system mandates Manrope, a variable sans in the same class as Inter and Geist. I kept it and capped weights at 400, 600 and 700.

Light mode. Genie is dark first. Light mode is a new, equal theme built from the same hues in OKLCH. Brand gradient survives on the wordmark and primary button only.

Capacity. Each week has 5 days of your time. Actions spend half days or full days. The session clock is information, never a penalty.

Style is not graded live. The board never hints at the right style. You learn from reason chips after the day resolves.

Elevation and material

elev.0Surface + 1px line. Cards, rows.
elev.1Raised tint. Hover, inset panels.
elev.2Material 90%, blur 16. Drawers, confirm bars.
elev.3Material + scrim, blur 24. Palette, dialogs.

Translucency only on overlays. Material is 90% opaque, so text contrast holds even where backdrop blur is unsupported or reduced transparency is on: the fallback is the same color at 100%.

Iconography

Genie ships no icon set, so this uses Lucide (flagged substitute) at 1.75 stroke, 16 and 18px, always paired with a text label or aria label. Icons never carry meaning alone.

Data viz rules

  1. Every metric is a horizontal bullet bar on one shared 0 to 100 scale, so any two people compare at a glance.
  2. Values are labelled directly, never only in a tooltip.
  3. One accent hue for all bars. Status uses the risk zone, an icon and words, never hue alone.
  4. A thin tick marks the value before today. The signed delta sits next to the number.
  5. Sparklines show trend only: no axes, same 0 to 100 scale in profiles, local scale in the team strip.
  6. Team view is small multiples: ten rows, four aligned columns.
